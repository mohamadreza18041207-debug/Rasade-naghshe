اتصال به سوپابیس

برای اجرای نسخه تک‌جایی، فقط یک‌بار کلیدهای سوپابیس را وارد کنید.
از Supabase → Settings → API بگیرید.

این مقادیر فقط در همین مرورگر (localStorage) ذخیره می‌شود.
فایل supabase-schema.sql را قبلش در SQL Editor اجرا کرده باشید.

🧩 اصلاح فایل پایه (فصل‌ها و فعالیت‌ها)

برای تغییر کلی فهرست فصل‌ها، موضوعات و فعالیت‌ها — بدون نیاز به کدنویسی — متن زیر را ویرایش کنید. این متن یک آرایهٔ JSON است؛ هر فعالیت باید حداقل chapter (نام فصل) و detail (شرح فعالیت) داشته باشد؛ کلیدهای topic (کلیات، اختیاری)، author (مولف پیشنهادی)، stageType (fixed یا staged)، stageLabel و report نیز قابل تنظیم‌اند.
